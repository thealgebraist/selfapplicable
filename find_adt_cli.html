A typed ADT find CLI

A finite predicate language is checked before it is interpreted against the filesystem. The implementation is a compact, explicit subset of standard find.

Example:
find_adt ROOT -name skip -prune -o -type f
Meaning: print the skip directory, do not descend into it, otherwise print regular files.

2. Language and command surface

find_adt ROOT
  [-name|-iname GLOB]
  [-path GLOB]
  [-type f|d|l]
  [-size [+|-]BYTESc]
  [-empty] [-prune]
  [-not] [-o]
  [-maxdepth N] [-mindepth N]
  [-print0]

The query is represented by these inductive-style alternatives:

True
Name(pattern, insensitive)
Path(pattern)
Kind(f | d | l)
Size(= | + | -, bytes)
Empty
Prune
And(left, right) | Or(left, right) | Not(child)

The type-stage analogue is check. It rejects empty patterns, unknown file kinds, invalid size operators, and malformed recursive predicate nodes. Only a checked predicate reaches filesystem evaluation.

3. Step-by-step evaluation

Assume this temporary tree:

ROOT/
├── a.c
├── b.txt
├── skip/
│   └── hidden.c
└── sub/
    └── c.c

Run:

find_adt ROOT -name skip -prune -o -type f

Step 1 — parse atoms

Name("skip")
Prune
Or
Kind('f')

The parser splits the expression at -o. Each side is a conjunction; the two groups become an Or node.

Step 2 — build the checked ADT

Or(
  And(Name("skip"), Prune),
  Kind('f')
)

check recursively validates both branches. The result is accepted because the name is nonempty, Prune is valid, and f is a supported kind.

Step 3 — visit ROOT/skip

Name("skip") = true
Prune           = true
left branch     = true
Or result       = true

The directory is printed. The separate prunes walk decision also sees that the successful branch contains Prune, so traversal stops below ROOT/skip. hidden.c is never visited.

Step 4 — visit ordinary files

ROOT/a.c:   left false,  right Kind('f') true  → print
ROOT/b.txt: left false,  right Kind('f') true  → print
ROOT/sub/c.c: left false, right Kind('f') true → print

Step 5 — output

ROOT/a.c
ROOT/b.txt
ROOT/skip
ROOT/sub/c.c

With -print0, the same paths are separated by NUL bytes rather than newlines, making the output safe for filenames containing whitespace or newlines.

4. Other evaluation examples

CommandADT/effect
-iname '*.C'Lowercases both filename and glob before matching.
-size +100cChecks regular file byte size greater than 100.
-empty -type dConjoins directory and empty-directory predicates.
-mindepth 1 -maxdepth 2Filters printing and bounds recursive traversal depth.
! -name '*.tmp'Wraps the name predicate in Not.

5. Verification

make check-find

The test creates its fixture tree with mktemp, checks recursive matching, depth, size, OR, empty directories, case-insensitive names, paths, NUL output, and pruning. The repository CI also runs this check; the current branch’s assembler-core workflow passed it.

This is not complete GNU find compatibility. Actions such as -exec and -delete remain intentionally outside this total predicate core.
