Self-applicable compiler to LLVM IR

The minimal total ADT language compiles itself through its own explicit quote/run interpreter, then lowers the normalized result to LLVM IR.

2. Input program

This is the complete example passed to the compiler:

(run
  (quote
    (let (nat 40)
      (let (nat 2)
        (add (var 0) (var 1))))))

Index 0 is the newest binding. Therefore the inner addition is 2 + 40.

3. Step-by-step evaluation

Step 1 — parse the ADT syntax

The parser builds a finite term tree:

Run {
  Quote {
    Let { Nat(40),
      Let { Nat(2), Add { Var(0), Var(1) } } }
  }
}

Step 2 — enter the self-applicable path

The compiler’s normal entry point does not directly evaluate the source. It constructs the object-language program:

Run(Quote(source))

This is the explicit stage transition. Quotation makes the source inert data; Run is what permits interpretation.

Step 3 — run the quote

normalize (Run (Quote source))
= normalize source

The quoted source is unwrapped only by the object-language Run rule.

Step 4 — normalize the first let

let (nat 40) body
→ body[0 := 40]

The environment becomes [40].

Step 5 — normalize the second let

let (nat 2) (add (var 0) (var 1))
→ add (var 0) (var 1), environment [2, 40]
→ add 2 40

Step 6 — reduce arithmetic

add 2 40 → nat 42

The normalized object-language result is now the ADT value Nat(42).

Step 7 — lower to LLVM IR

; generated by the self-applicable ADT compiler
source_filename = "minimal-adt"

define i64 @main() { ret i64 42 }

This text is accepted by llvm-as. The repository test runs the compiler and verifies that the generated module contains ret i64 42.

4. What “self-applicable” means here

The compiler is written in C++ as the executable bootstrap, but its compilation decision is made by the language’s own evaluator: the compiler explicitly creates and normalizes (run (quote source)). Thus the same staged semantics used for ordinary programs is used to process the program being compiled.

This is a total, bounded self-application experiment. It does not yet compile arbitrary recursive functions, pointers, effects, or general LLVM control flow. Those require additional ADT constructors, a type-stage specification, and corresponding LLVM lowering rules.

5. Reproduce it

make check-llvm

The test creates temporary files with mktemp, invokes the compiler on examples/selfapp_llvm.min, assembles the output with llvm-as, and checks the normalized result.
